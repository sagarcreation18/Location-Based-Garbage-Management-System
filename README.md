# EcoTech Smart City login page

Static frontend for the **Location-Based Garbage Management System for Smart City**. Open `index.html` in a modern browser (or serve the folder using any static server).

## Included

- Responsive premium EcoTech split-screen interface
- Citizen, Driver, and Admin portal selection
- Email validation, password reveal, and demo sign-in state
- Phone demo OTP generation, paste support, and verification
- Google OAuth placeholder, toasts, ripple interactions, keyboard support, and saved dark mode

The project deliberately has no backend. Replace the handlers in `js/app.js` with PHP/MySQL/API calls when integration begins.
